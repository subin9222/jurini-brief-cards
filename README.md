# 주린이 브리핑 카드뉴스

인스타그램 @jurini.brief 의 일일 증시 카드뉴스 이미지 저장소입니다.

- `cards/YYYY-MM-DD/` : 날짜별 카드 이미지·캡션
- `WEEKEND.md` : 주말(토: 미국 주간 결산, 일: 미국 경제 공부) 작업 절차
- `tools/` : 카드 렌더러와 디자인 자산
- `WORKFLOW.md` : 매일 작업 절차
- `THREADS.md` : 며칠 이어지는 이슈(연재) 장부
- `METRICS.md` : 게시물 반응 기록(좋아요·댓글·공유·저장)

※ 본 저장소의 콘텐츠는 정보 제공 목적이며 투자 권유가 아닙니다.
